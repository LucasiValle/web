Protocolo HTTP

O que é o HTTP?

HTTP significa HyperText Transfer Protocol. É o protocolo usado na Web para comunicação entre o navegador (cliente) e o servidor.

Ele funciona através de requisições (requests) e respostas (responses). O navegador envia um pedido ao servidor, e o servidor devolve a resposta com a página solicitada.

Exemplo de uma Requisição (Request)

    GET /index.html HTTP/1.1
    Host: www.exemplo.com
    User-Agent: Mozilla/5.0
    Accept: text/html

Explicação dos campos:

  • GET: método usado (pode ser GET ou POST)
  • /index.html: página solicitada
  • Host: endereço do servidor
  • User-Agent: identifica o navegador
  • Accept: tipo de conteúdo aceito

Exemplo de uma Resposta (Response)

    HTTP/1.1 200 OK
    Date: Sat, 02 Nov 2025 15:30:00 GMT
    Server: Apache
    Content-Type: text/html
    Content-Length: 150

Explicação dos campos:

  • HTTP/1.1 200 OK: versão do protocolo e código de status (200 = sucesso)
  • Date: data e hora da resposta
  • Server: servidor usado
  • Content-Type: tipo de arquivo enviado (HTML, imagem, texto, etc.)
  • Content-Length: tamanho do conteúdo

Como o HTTP é usado na Web

Quando você digita um endereço como https://www.google.com no navegador:

  1. O navegador envia uma requisição HTTP para o servidor do Google.
  2. O servidor processa o pedido.
  3. Ele devolve uma resposta HTTP com o código HTML da página.
  4. O navegador exibe a página para o usuário.

Principais métodos HTTP

  • GET: Pede informações do servidor.
  • POST: Envia dados para o servidor.
