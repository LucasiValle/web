O que é JavaScript?

JavaScript foi criado para tornar a web interativa, ser acessível a iniciantes e fortalecer a competitividade da Netscape no início da internet.

JavaScript no navegador serve para tornar a página interativa, manipulando a interface e reagindo às ações do usuário, mas com acesso limitado por segurança. Já no servidor, ele roda com mais permissões, podendo acessar banco de dados, arquivos e realizar a lógica de backend, sem lidar com a interface visual.

O conceito de sandbox no navegador significa que o JavaScript é executado em um ambiente isolado e controlado, onde só pode acessar recursos permitidos pelo próprio navegador. Esse isolamento impede que scripts mexam diretamente no sistema do usuário, leiam arquivos locais, instalem programas ou acessem dados de outras páginas sem autorização. Em resumo, a sandbox funciona como uma “caixa de segurança” que protege o usuário contra ações potencialmente perigosas de códigos executados na web.
